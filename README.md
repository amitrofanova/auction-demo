# Аукцион

Локальная демонстрация торгов: один лот, два покупателя и продавец на одной странице. Сервер — источник правды. Состояние комнаты живёт в памяти процесса и пропадает вместе с ним. База и внешний бэкенд не нужны.

Колонка отправляет на сервер только намерение участника. Итог ставки, лидера и конец раунда считает сервер.

Сейчас на странице три колонки одного лота. Продавец создаёт аукцион и запускает его отдельной кнопкой. Покупатели видят смену стадии без перезагрузки. У каждой колонки своё соединение.

## Запуск

```bash
npm install && npm run dev
```

Откройте http://127.0.0.1:5173 . Клиент — Vite на порту 5173, сокет — на 8787. Страница ходит на `ws://127.0.0.1:5173/ws`, Vite проксирует этот путь на сервер.

Если 5173 уже занят: `WEB_PORT=5191 WS_PORT=8791 npm run dev` и открывайте http://127.0.0.1:5191 .

## Проверки

```bash
npm test
```

Правила лота, снимок и комната проверяются без браузера. Страница показывает карточку лота и пульт продавца.

## Как разложено

- `packages/domain` — правила лота, разбор команд и снимок для участника. В снимке покупателя нет ленты, имени лидера и чужого потолка.
- `apps/server` — вебсокет и комната. После join сокет закреплён за участником, каждому уходит свой снимок, конец раунда закрывает один таймер.
- `apps/web` — Vue 3, три колонки и три сокета.
