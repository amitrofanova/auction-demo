# Аукцион

Локальная демонстрация торгов: один лот, два покупателя и продавец на одной странице. Сервер — источник правды. Состояние комнаты живёт в памяти процесса и пропадает вместе с ним. База и внешний бэкенд не нужны.

Колонка отправляет на сервер только намерение участника. Итог ставки, лидера и конец раунда считает сервер.

Сейчас на странице три колонки одного лота. Покупатель ставит сам или задаёт потолок автоброкера. Ленту, имя лидера и чужой потолок видит только тот, кому они положены.

## Сценарий на полминуты

1. Откройте страницу. Слева Покупатель 1, в центре Покупатель 2, справа Продавец. У каждого своё соединение.
2. У продавца оставьте 10 000, шаг 1 000 и 2 минуты, нажмите «Создать аукцион», затем «Запустить».
3. У Покупателя 1 нажмите «Поставить». Сумма сменится в двух других колонках. Ленту и имя лидера видит только продавец.
4. У Покупателя 2 задайте потолок 20 000 и нажмите «Включить». Перебейте ставку у Покупателя 1: ответ придёт сам, без нажатия во второй колонке.
5. Продавец нажимает «Завершить». Победитель видит итог, второй покупатель — «Торги завершены», время — «закрыт».
6. «Перезапустить», затем снова «Запустить». Условия те же, ставки пустые, новый раунд сам не стартует.
7. Оборвите соединение одной колонки: она пишет «связь пропала». Новый сокет делает join, и колонка заменяет состояние снимком.

## Запуск

```bash
npm install && npm run dev
```

Откройте http://127.0.0.1:5173 . Клиент — Vite на порту 5173, сокет — на 8787. Страница ходит на `ws://127.0.0.1:5173/ws`, Vite проксирует этот путь на сервер.

Если 5173 уже занят: `WEB_PORT=5191 WS_PORT=8791 npm run dev` и открывайте http://127.0.0.1:5191 .

## Проверки

```bash
npm test
```

Правила лота, снимок, комната и догон снимка проверяются без браузера. Страница показывает торги, автоброкер и потерю связи.

## Как разложено

Четыре слоя, зависимость только вниз:

1. **Домен** — `apply(state, command, now)`. Часы приходят аргументом, таймера внутри нет.
2. **Проекция** — из одного состояния снимок для конкретного участника.
3. **Комната** — сокеты, рассылка своих снимков, один таймер на `endsAt`.
4. **Три колонки** — три сокета. Колонка показывает снимок и отправляет намерение.

- `packages/domain` — правила лота, разбор команд и снимок для участника. В снимке покупателя нет ленты, имени лидера и чужого потолка.
- `apps/server` — вебсокет и комната. После join сокет закреплён за участником, каждому уходит свой снимок, конец раунда закрывает один таймер.
- `apps/web` — Vue 3, три колонки и три сокета. Старый `seq` колонка не применяет.
